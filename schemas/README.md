# Schemas

Maschinenlesbare Schemata für soziale Operationen, RLS-Item-Views, Quests, Relationen und Rollout-Artefakte.

Die Schemata in diesem Repository sollen backend-agnostische RLNP-Views wie Quests, QuestRuns, Confirmations und Relationen beschreiben. Sie sollen kein eigenes Format für signierte Verifikationen oder Attestationen definieren. Das legt die technische Spezifikation fest; dieses Repository beschreibt nur App-Projektionen davon.
